Política de Privacidade

Faturas Inteligentes — aplicação pessoal e local. Última atualização: 16 de outubro de 2026.

Dados a que a aplicação acede

Com a autorização expressa do utilizador, a aplicação acede à sua conta Gmail através do âmbito https://www.googleapis.com/auth/gmail.readonly (acesso só de leitura), exclusivamente para encontrar mensagens com faturas em PDF e descarregar esses anexos.

A aplicação não apaga, move, marca nem envia mensagens e não altera nada na conta.

Como os dados são usados e guardados

  • Os anexos e os dados extraídos (fornecedor, número, datas, valores) são guardados apenas no computador do utilizador.
  • O processamento, incluindo a leitura dos PDFs e o reconhecimento de texto, é feito localmente.
  • O token de acesso fica guardado no Gestor de Credenciais do Windows, nunca em ficheiros nem em registos.
  • Nenhum dado é enviado para servidores do autor nem para terceiros. Não existem anúncios, análises nem partilha de dados.

Utilização limitada de dados da Google

O uso e a transferência para qualquer outra aplicação de informações recebidas das APIs da Google respeitam a Política de Dados do Utilizador dos Serviços de API da Google, incluindo os requisitos de Utilização Limitada. Os dados do Gmail são usados apenas para o fim descrito acima, não são vendidos e não são lidos por pessoas.

Revogar o acesso e apagar dados

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Para apagar os dados, basta eliminar a pasta das faturas e a base de dados local no computador.
